## Historical purpose

This plan authorized the interruption of premature report-first implementation and
required Ali and the AI assistant to perform the intended UpgradePilot runtime
manually on real dependency-update cases.

It established the need to investigate:

```text
invocation and identity
→ evidence acquisition and preservation
→ observation, interpretation, findings, and uncertainty
→ repository-specific relevance
→ bounded decision and reports
→ user follow-up, rerun, and supersession
```

That correction produced the governed `product-simulation/` workspace and the
completed S001, S002, and S003 scenarios.

Incremental implementation is valid only when the owning product responsibility is
understood well enough that the slice is not locally correct but globally
irrelevant.

This file remains historical evidence of that correction. Do not use it as the
current project plan or current continuation.
