### Visible response contract

The experiment-owned response envelope has exactly `evidence_worksheet` and `report`. `report` retains the existing strict report schema. The worksheet is an ordered array of concise rows: `finding_type` (`source_fact`, `material_relation` or `unresolved_binding`), `statement`, the existing asserted/inferred/unresolved `status`, offered typed `evidence`, and `missing_observation`. Reuse existing field bounds and a bounded array rather than introduce a semantic graph or new citation class.

The common instruction asks for source facts first, then material relations/differences, then unresolved bindings, and finally the report. Source-comparison tasks explicitly ask to compare supplied signatures with actual forwarded arguments; CI tasks ask to connect workflow steps, tool configuration and dependency inputs while distinguishing static declarations from observed execution. These are reusable operations, not a desired parameter name, expected answer, solved path or risk verdict. Existing task-specific scope limits remain visible.

This worksheet is a requested factual work product, not hidden reasoning or a request to reveal internal thought. Requested output order does not prove the model's internal reasoning order or a causal benefit. Record whether the requested worksheet/member order is followed; JSON member order alone does not establish semantic failure or the model’s internal reasoning order. Missing or materially false worksheet work fails candidate-method adequacy even if a final sentence happens to be correct. Structural validity alone never qualifies the method.

Both worksheet and report may reference only the exact offered `(kind,id)` pairs. Worksheet rows are model-authored interpretations, not new observations, typed Workspace evidence or corroborating citations. The final report must continue citing original source/native references. Generic uncertainty cannot replace directly observable facts; unsupported reassurance cannot be excused by a caution in another field.

## Semantic comparison and review

Reuse the exact20 frozen obligations and adjudication discipline. A case is adequate only if every required material obligation is supported or specifically justified unresolved, with zero decision-critical false/unsupported advice or authority promotion, usable source scope and justified next work or a scoped conclusion. Candidate review records both original and any explicitly adjudicated labels; never move the gate after seeing output. Read every worksheet/report field, not only selected claims. A materially false worksheet row or recommendation fails the method even if a correct final sentence appears elsewhere.

Keep these questions separate:

1. Were direct source facts accurately extracted and attributed?
2. Were the necessary source relationships established or specifically unresolved?
3. Did the report preserve those findings and their limits without promotion or contradiction?

These are diagnostic views of the same obligations, not extra weighted scores or independent samples. Compare case-level adequacy, source-reasoned errors, captured-consumer contrast, unresolved premises, completion and actual input/output/time/operation cost with the immutable reference. Report partial improvements without relabelling a failed case adequate. A higher citation count, longer answer or fuller worksheet is not success.

The reviewer remains AI-assisted and source-aware with prior exposure, not blinded independent human acceptance. Freeze generic worksheet-to-obligation review guidance before candidate output. Reviewer labels/prose, original reports, adjudication answers and this plan must remain outside model construction. Verify allowlisted construction rather than blacklist words that legitimately appear in source. Unresolved consequential reviewer disagreement makes the decision inconclusive.

This is a historical, one-sample-per-case development comparison, not a randomized concurrent control or reliability study. The reference is not rerun. Even complete candidate success supports only a promising method bundle on exposed cases; no causal claim, model ranking, statistical improvement or product adoption follows.

## Execution sequence and stopping rules

1. **Authorize implementation and orient the responsibility.** Inspect exact current source/tests and the binding. Implement only the candidate composition and required proof; use the same cycle's preservation or a clearly linked Build cycle without claiming predecessor learner closure.
2. **Prove the composition offline.** Complete the focused checks above. Bind new source, unchanged source selections and reviewer criteria in fresh owner-only roots. Old baseline roots remain immutable.
3. **Authorize one measurement preparation.** Revalidate local assets/SDK/ownership, load the declared point and retain the actual profile plus every full rendered fit, including rejected fits. No prediction or executable freeze on failure; confirm owned unload/client release.
4. **Freeze and activate exactly once.** Publish real resolved source/SDK/input/reviewer/profile/presentation/wrapper/projection identities, role order, all ceilings and complete fit. Obtain explicit matching-freeze activation under the selected implementation/run authorization. This planning artifact supplies neither that activation nor placeholders that may reach execution.
5. **Run the independent synthetic report canary.** Exercise worksheet shape/references, projection, every report field, usage/settings/prompt/instance correspondence and publication. No semantic-case solution enters it. Failure withholds all cases without retry.
6. **Run the four fixed cases once.** No intermediate grading feedback or prompt/order changes. A hard control/identity/input/shape/publication failure or unknown usage withholds remaining predictions. Known semantic failure discovered in later review does not retrospectively remove a case or authorize a rerun. Complete comparable unpublished content may still be source-reviewed while retaining its operational failure.
7. **Review, preserve and decide.** Reconcile actual costs, all original/adjudicated labels, output/source premises, deviations, retention and proof limits. Complete proportionate evidence-backed learning/handoff; do not infer learner mastery or close predecessor D/E automatically.
