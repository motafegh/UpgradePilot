## Proof and stop boundary

Engineering pass requires relevant tests, both saved-role recovery paths, exact source/reference preservation and measured real-provider execution of the enlarged schema without truncation or accounting mismatch. Development semantic pass additionally requires zero critical unsupported/misattributed meanings, correct operation polarity/timing, useful required positives and visible other changes/specific unassessed material across the full set. All-unknown output fails usefulness.

Independent semantic admission, a second normally acquired target-PR case, target exposure/impact and maintainer usefulness remain separate parent-plan obligations. Do not mark this whole role accepted from code tests or a repaired known case.

If critical semantic failures persist, stop with **REVISE**, preserve the failed v2, and design the smallest discriminating comparison: two-stage source comprehension then structured encoding, or another suitable local model under equivalent inputs. Those alternatives add latency/model-call or deployment variables and require separately frozen methods; they are not automatic retries or presumed improvements.
