## Screening method

Use public PR metadata and changed files to freeze revisions and exact-version candidates. First look for direct HTTPX calls that pass the removed `app` or `proxies` keyword, and adapter calls that admit old Starlette. Contrast with a second package family where published migration notes name a specific API removal. For serious candidates, trace the exact-head source and determine whether current UpgradePilot owners can admit the input and recover relevant evidence. Source-only archives are treated as data. No target code or workflow execution. Prefer cases with distinct findings over repeated copies of the same mechanism.
