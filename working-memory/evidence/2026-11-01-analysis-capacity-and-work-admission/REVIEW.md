## Delivered behavior

- Explicit input/2→comparison/3 opt-in, with operational contract/configuration binding. Legacy ordinary input/1, comparison/2 and curated/1 keep existing interpretation and missing-fact refusal.
- Non-executing AST scan of all selected Python source under per-file/aggregate node limits, even when some source remains unexamined.
- Conservative static import-component scope; captured native counterparts stay in one whole-file admission group. Entry modules and direct target import seeds precede broader support/neighbors. Conditional imports remain conditional; static scope supplies no runtime or absence proof.
- Whole files fit or remain unexamined; no selective truncation of call facts or known-witness path input. All original text remains in the source companion and inspectable offline.
- Exact typed structure accounting:196,608 tokens for normalized facts,32,768 for candidates/pairs, leaving room inside the unchanged final262,144-token guard for metadata/gaps. Final codec/output refusal remains authoritative. Candidate structure exhaustion is a visible gap.
- Per-file typed binding-step tables retain every binding step/order/reason/alternative, with checked integer references. Cold decoding validates each shared step's source/span once and every binding's references/state. No opaque strings or fact/premise deletion.
- Fixed source/fact/admission/work/paired-group/path closure. An unexamined unit cannot silently become analyzed or supply a path witness; legacy missing facts still refuse. Rendered output distinguishes retained source from analysis coverage.
