## What is implemented

[The diagnostic](../../../tools/capture_report_sources.py) runs the unchanged normal application and report projection while retaining its actual HTTP observations in a separate private source packet. The existing UpgradePilot CLI, public saved-report schema and domain owners are unchanged. The observation point preserves streamed body/transport failures, partial/unread bodies and native result meanings; it does not derive a baseline from report findings.

This is a synchronous developer diagnostic on the WSL/POSIX control plane, with bounded source/byte/request/time handling and zero admitted model calls. No new framework/dependency or generic evaluation platform. Existing private/report formats are not promoted to product replay or universal raw retention. source-index.json contains request identities/status, selected response headers and retained-prefix hashes; it contains no report conclusions or expected answers. Both future review conditions can access the same source packet, with only the assisted condition additionally receiving the actual report. Case selection, navigation/task parity and independent adjudication remain unqualified study work.

For a separately selected future capture, the invocation shape is:

```bash
PYTHONPATH=src:. .venv/bin/python3 -m tools.capture_report_sources \
  --contract /absolute/path/to/new-operational-contract.json \
  --output /absolute/private/path/to/new-capture-directory
```

The parent must exist and output must be new/outside the checkout; existing destinations are refused. Set exact repository/PR/base/head/package/old/proposed versions and explicit positive request/body/aggregate/time limits as in [this historical contract](contract.json), using a new contract/horizon for new work. Do not rerun this frozen attempt or reuse its occupied output path. The CLI isolates anonymous transport at process scope; the internal capture function assumes that CLI environment or an explicitly controlled test caller. No model fallback: a model request stops and preserves partial sources without a completed normal report.
