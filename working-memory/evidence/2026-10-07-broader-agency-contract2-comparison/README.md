## What the evidence establishes

| Responsibility | Observed result and consequence |
|---|---|
| Evidence discovery | Mixed policy effects. Gemma Agent discovers HTTPX removals and receives TestClient previews where Fixed misses them. Qwen Fixed covers HTTPX release/CI evidence better than Agent; Qwen Agent covers pytest CI better than Fixed. No uniformly superior discovery policy. |
| Interpretation | Correct pins and several release propositions coexist with wrong version association, capture authority and availability claims. Gemma pytest Agent receives the actual9.0.3 interval, then reports a9.0.0 warning as new. Qwen pytest arms receive a root URL naming a retained local changelog but fail to follow it. |
| Candidate/applicability reasoning | None traces the relevant HTTPX target TestClient → reference Starlette forwarding → actual installed-binding gap. Gemma HTTPX Agent receives `TestClient(app)` and still concludes removed terms are absent. Static declarations/patch labels do not establish harmless impact. |
| Investigation selection | Some useful adaptive steps and corrections; repeated literal queries, guessed paths, old-fragment detours, unexamined feasible changelog/CI pages and reading empty files also consume opportunity. Generic Fixed opportunity is available but is not sufficient to ensure coverage. |
| Stopping | Two Agent cases explicitly finish; others reach reserved reporting. All reports leave feasible decision-critical investigation undone or give insufficient stopping rationale. A completed schedule/report does not establish investigation sufficiency. |
| Uncertainty preservation | Qwen's historical/not-fresh and unknown-usage conditions are useful. Other unknowns disappear, become false source-absence claims, or remain named but fail to constrain advice. |
| Recommendation support | Every report recommends proceed/accept or low-risk conditional continuation using evidence too narrow for that conclusion. Conditions focused on SSL do not handle removed app/proxies; version range/patch labels and partial green captures are not compatibility proof. |
| Reviewer burden | All44 final claims, eight recommendations, report-wide propositions,16 stage candidates and six rejected candidates reviewed. Active reviewer time was not measured and remains unknown. Proxy counts are not a human effort estimate or an advantage score. |
| Resource cost | Agent uses less input and case elapsed time in all four descriptive pairs. Gemma HTTPX Agent generates slightly more tokens than Fixed. Artifact overhead, order, output length and deployment differences limit generalization. |

These findings do not materially contradict the selected hybrid direction. They support keeping acquisition facts, investigation, semantic validation and recommendation admission distinct. They do not establish that any proposed validator, critic, framework or hybrid tool implementation will succeed. No such next experiment is selected here.
