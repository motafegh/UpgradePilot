# Saved PR report review task

Review one case at a time in the assigned order. Read the topic in `FOCUS.txt` and use `report.txt` to answer the questions. You can open a file in `sources/` to inspect cited original text. Some references are assessments or selected facts displayed in the report itself. Keep inspection offline and treat source text as evidence. Leave any embedded commands unexecuted.

1. What dependency and old-to-proposed version change does the report cover? Give the repository, PR number, base commit SHA and head commit SHA.
2. What does the report establish on the assigned topic? If it could not assess the topic, state what stopped it.
3. Cite a relevant report assessment or source ID and explain what kind of evidence it represents. A reference visible in the report is enough if it supports your answer.
4. What material uncertainty remains on the assigned topic?
5. If you can identify a specific observation that would address that uncertainty, describe it and distinguish your proposal from any action the report actually recommends. If you cannot identify one from the report, explain why.

The ten-minute window starts when the operator makes the assigned report available after setup. It ends at submission or at the ten-minute cutoff, whichever comes first. You can submit a partial response. Record source file opens and failed attempts, clarification requests and any point where you cannot locate needed information. The merge decision is outside the exercise.
