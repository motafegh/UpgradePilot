## Capture and retention boundary

The available GitHub connector exposes the structured provider fields used by the current diagnostic path plus repository source/diff text, but it does not export original HTTP bodies/headers byte-for-byte. Manifests therefore label provider API material as structured provider captures, not HTTP-wire archives. Authoritative source/diff artifacts are retained losslessly with byte size, SHA-256 and Git blob identity.

Logs/workflow artifacts were not retained because they are not material to the current declared correlation responsibilities and would add size/security/privacy surface. A later diagnostic needing them must capture that evidence explicitly.
