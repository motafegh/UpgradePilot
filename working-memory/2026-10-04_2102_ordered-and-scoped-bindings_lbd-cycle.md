2. Review found that treating `return` as generic unsupported control flow needlessly erased valid local imported calls in return expressions. Return expressions are now analyzed before the following syntactic statements receive an explicit termination limit. This does not propagate return values between functions.
3. A first unsupported-write footprint missed subscript receiver roots. A specific loop/subscript control led to tracking receiver mutations independently from local names. Repairs extend the earliest footprint/alias/scope owners: preserve receiver mutation effects across unsupported regions, invalidate dynamic namespace operations through copied aliases, include class global-write declarations, and limit explicit custom class namespaces. Committed regressions now cover each mechanism.
