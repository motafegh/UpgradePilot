## Material gap in sampled evidence

The exact test workflow requests Python 3.10 and runs pip install from requirements.txt before pytest. Both live adapter samples declare Requires-Python >=3.11. PyPI records their first uploads in October and November 2026, after the historical PR merged. The sample is useful for source analysis. It cannot represent what the test workflow could install under normal Python 3.10 compatibility enforcement or what the historical PR installed.
