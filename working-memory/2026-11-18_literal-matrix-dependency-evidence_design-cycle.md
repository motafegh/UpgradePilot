## Method decisions

The [proposed ADR](../docs/architecture/ADR-0014-literal-matrix-specialization-and-scoped-ci-evidence.md) records the full recommendation.

- A provider-owned companion expands the complete admitted literal matrix and retains typed coordinates and source provenance. Direct matrix lookup is a bounded expression subset. Fields retain their provider context restrictions.
- Generated scripts retain a separate digest, replacement provenance and generated-byte coordinate space. Every consumer needs an explicit variant-context identity.
- Prefer source-defined names and ordered step identities for unique reported correspondence. The retained MapProxy case needs no default matrix job-name convention or production graph acquisition for this proposed route.
- The earlier whole-display swap exposed the trusted provider premise. Treating that synthetic rewrite as a universal veto on correspondence imposed a stronger requirement than the reported proposition needs. It remains relevant when a claim calls for independent runtime attestation.
- Preserve the existing command rule and propose a distinct later-sequential Bash/sh relation. Qualification must reject early termination, altered shell/error context, status masking and unsupported syntax before accepting MapProxy's second install.
- Keep per-variant failures and unknowns through aggregation and recovery. An existential positive aggregate cannot stand for all-combination coverage.

The scalar contract initially admits unambiguous strings, core boolean/null values and exact decimal integers, with homogeneous comparison kinds and explicit refusal of case-only comparison collisions. These boundaries avoid conflating raw BaseLoader text with typed hosted values. Object-valued axes, unqualified number conversion, ambiguous comparisons, runtime-generated matrices and broader expressions remain visible with concrete re-entry conditions. The limitation is in interpreting missing or unqualified provider semantics, while the chosen consumer still covers all four MapProxy variants.
