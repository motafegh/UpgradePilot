## Learner-owned conclusions

The learner now owns the current-depth distinctions for complete stateless history and evidence/reference authority:

- A complete stateless interaction history needs both the model's previous request and the system's returned observation. The request preserves what the model actually attempted; the observation preserves what the system actually delivered. An observation alone can lose the action arguments that produced it and can therefore make repeated behavior impossible to interpret cleanly.
- Model-authored requests and interactions do not grant citation authority. Citation authority comes only from an eligible typed reference actually delivered by the system in a returned observation.
- Canonical packed/accounting bytes and the model-readable presentation may use different formats as long as they correspond faithfully: no evidence, request arguments, reference IDs, observation content, omissions or authority semantics may be silently changed.
- A reference-like ID manufactured by the model remains model-authored history, not evidence authority. Repeating it in a later stateless request does not upgrade it into a valid citation.

These conclusions should later be reconciled against completed Build/Verification evidence before reuse in formal D.
