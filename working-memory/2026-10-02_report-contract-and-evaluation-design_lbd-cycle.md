## Design choices and alternatives

- One semantic projection shared by human rendering and explicit versioned JSON encoding; avoid two inference paths or reflective dumping of internal dataclasses.
- Offline reopening reconstructs the report only. It neither refreshes sources nor reruns investigation. Preserve original identities and declare missing content/provenance.
- File export rather than database/event log: review/evaluation needs an inspectable named result; cross-run querying/recovery has not justified extra machinery.
- Standard-library parsing/encoding/file handling is the simplest existing baseline. Strict versions/references/integrity and proportionate malformed-input handling are boundary obligations, not independent evidence truth.
- Report-generation time and ID identify the produced report, not the historical time of every source or a reconstructed orchestration attempt. Copy only retained provider times/transformations; do not invent missing ones.
- A digest detects consistency/corruption, not authenticity. No source truth follows from valid JSON or a matching hash.
- Same-evidence baseline/report comparison isolates presentation utility. Curated packets test supplied-evidence presentation separately; independent task review is necessary for usefulness.
