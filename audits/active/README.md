# Active Audits

Audit records in this folder contain validated findings that are explicitly selected as inputs to the current engineering responsibility.

They remain **non-controlling evidence**: the active plan, specifications/ADRs where applicable, source/tests, and `MEMORY.md` still own execution, stable decisions, behavior, and live continuation.

Move an audit out of this folder when its findings have been dispositioned by the owning work: use `../absorbed/` when the material conclusion has been incorporated into stronger owners, or `../deferred/` when it remains valid but is no longer selected for current work.
